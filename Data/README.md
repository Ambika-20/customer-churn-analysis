# 📂 Dataset | Customer Churn Analysis

> Understanding customer behaviour through data.

### Dataset at a Glance

| | |
|---|---|
| **Industry** | Telecommunications |
| **Records** | 6,418 customers |
| **Attributes** | 32 columns |
| **Format** | CSV |
| **Tools Used** | Excel · MySQL · Power BI |

### 🔎 What's Inside?

The dataset captures customer demographics, service subscriptions, billing details, contract information, and churn behaviour.

- 👥 **Customer Profile** — age, gender, marital status, and location
- 💳 **Account & Billing** — contract type, payment method, monthly charges, and revenue
- 📡 **Services & Offers** — internet services, additional features, and value deals
- 📉 **Churn Behaviour** — customer status, churn category, and reported reasons for leaving

### 🧹 Data Preparation

The data was inspected using Excel and SQL to check missing values, duplicate customer IDs, and column naming issues. Blank values in `Value_Deal` were interpreted as **No Deal** for this analysis.
